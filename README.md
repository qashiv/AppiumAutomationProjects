This project is designed with a scalable and maintainable automation framework, and includes:

End-to-end test coverage for General Store Apk
Implementation of Page Object Model (POM) for better code reusability
Modular framework structure with utility classes
Cross-context handling (Native ↔ WebView)
Integrated reporting using Extent Reports with screenshots
Exception handling and synchronization strategies for stability
I focused on writing clean, reusable, and production-ready code while following best practices in mobile test automation.
